How I work

Three habits behind every analysis.

I'm not tied to one industry. The same approach has carried me across higher-ed, consumer analytics, finance, healthcare, and marketing.

01

Start with the decision, not the dataset

Before touching data I ask what will change if the answer is yes or no. In the churn project that question turned a model into a campaign size and a call list.

02

Earn trust in the number first

Validation, reconciliation, and plain-English reasons come before polish. I would rather ship an interpretable model people believe than a black box they ignore.

03

Ship it where people will use it

Dashboards, apps, and call lists beat notebooks. I build in Tableau, Power BI, and Streamlit so the work does not die in a file.
